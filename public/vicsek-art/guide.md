# Vicsek 모델 쉬운 설명서

## 물고기떼는 왜 함께 움직일까?

바다에서 물고기 수백 마리가 한꺼번에 "확!" 방향을 바꾸는 걸 본 적 있나요?
새떼가 하늘에서 물결치듯 움직이는 것도요.

**리더가 있을까요? 아닙니다!**

놀랍게도 물고기떼에는 대장이 없습니다.
각 물고기는 아주 단순한 규칙 하나만 따릅니다:

> **"내 주변 친구들이 가는 방향을 보고, 나도 비슷하게 가자!"**

이 간단한 규칙만으로 수천 마리가 마치 하나의 생물처럼 움직입니다.
이걸 수학으로 만든 것이 **Vicsek(빅섹) 모델**입니다.

---

## Vicsek 모델이란?

1995년, 헝가리의 물리학자 **타마스 빅섹(Tamás Vicsek)** 선생님이 만든 모델입니다.

### 규칙은 딱 2개

```
규칙 1: 주변 친구들의 평균 방향으로 가기
규칙 2: 약간의 실수(노이즈) 더하기
```

이게 끝입니다! 이 두 가지만으로 물고기떼, 새떼, 벌레떼의 움직임이 만들어집니다.

### 비유로 이해하기

운동장에서 눈을 가리고 걷는다고 상상해보세요:

1. 귀를 기울여 **내 주변 3미터 안에 있는 친구들**의 발소리를 듣습니다
2. 친구들이 **대충 어느 방향**으로 가는지 느낍니다
3. 나도 **그 방향으로** 걷습니다
4. 하지만 눈을 가렸으니 **약간 삐뚤빼뚤** 걷게 됩니다 (이게 노이즈!)

모든 사람이 이 규칙을 따르면?
→ 처음에는 뒤죽박죽이지만, 시간이 지나면 모두 같은 방향으로 걷게 됩니다!

## 코드에서 쓰이는 개념들

### 1. 입자 (Particle) = 물고기 한 마리

```
물고기 한 마리가 가진 정보:
- 위치: 지금 어디에 있는지 (x, y 좌표)
- 방향: 어디를 향해 가고 있는지 (각도 θ)
- 속도: 얼마나 빨리 가는지 (v) - 모두 같은 속도!
```

### 2. 상호작용 반경 (R) = 귀가 들리는 거리

```
나한테서 R 거리 안에 있는 친구만 볼 수 있어요.
너무 멀리 있는 물고기는 모르는 남이에요.

R이 크면 → 멀리 있는 친구까지 따라감 → 큰 무리
R이 작으면 → 가까운 친구만 따라감 → 작은 무리 여러 개
```

### 3. 노이즈 (η, 에타) = 실수하는 정도

```
η = 0   → 완벽하게 친구를 따라감 (로봇처럼)
η = 작음 → 약간 삐뚤빼뚤 (물고기떼처럼 자연스러움)
η = 큼   → 많이 삐뚤빼뚤 (취한 사람처럼)
η = 아주 큼 → 완전 제멋대로 (혼돈!)
```

이 노이즈가 핵심입니다! 노이즈가 없으면 모두 같은 방향으로 직진만 합니다.
적당한 노이즈가 있어야 무리가 갈라졌다 합쳐지는 자연스러운 움직임이 나옵니다.

### 4. 정렬 (Alignment) = 평균 방향 따라가기

```
내 주변에 친구 3명이 있다면:
- 친구 A: 동쪽으로 가는 중 (→)
- 친구 B: 북동쪽으로 가는 중 (↗)
- 친구 C: 남동쪽으로 가는 중 (↘)
- 나: 서쪽으로 가는 중 (←)

평균 방향 = 동쪽 (→)
→ 나도 동쪽으로 방향을 바꿈!
```

### 5. 분리 (Separation) = 부딪히지 않기

```
물고기끼리 너무 가까우면 부딪혀요!
그래서 아주 가까운 친구는 밀어냅니다:

"너 너무 가까워! 나한테서 좀 떨어져!"

이 힘이 없으면 물고기들이 한 점에 뭉쳐버립니다.
```

### 6. 흐름장 (Flow Field) = 보이지 않는 바람

```
바다에는 해류가 있고, 하늘에는 바람이 있어요.
Perlin 노이즈로 만든 "보이지 않는 바람"이
물고기들을 부드럽게 이리저리 밀어줍니다.

이 바람이 없으면?
→ 물고기가 한 방향으로만 쭉 가버림 (지루!)

이 바람이 있으면?
→ 물고기 무리가 이리저리 휘어지며 예쁜 패턴 생성!
```

### 7. 관성 (Inertia) = 갑자기 못 꺾음

```
자동차가 갑자기 180도 돌 수 없듯이,
물고기도 방향을 서서히 바꿉니다.

관성이 크면 → 천천히 부드럽게 회전 (큰 배처럼)
관성이 작으면 → 빠르게 꺾음 (작은 물고기처럼)
```

### 8. 경계 처리 = 화면 끝에서 어떻게 할까?

```
방법 1 - Wrap (순간이동):
  화면 오른쪽 끝으로 나가면 → 왼쪽에서 나타남!
  마치 지구가 둥근 것처럼.

방법 2 - Steer (벽 피하기):
  벽에 가까워지면 → 방향을 틀어서 안쪽으로 돌아옴!
  실제 수족관의 물고기처럼.
```

## 매 프레임마다 일어나는 일 (순서대로)

```
1. 각 물고기마다 주변 친구 찾기 (상호작용 반경 안)
   ↓
2. 친구들의 평균 방향 계산하기 (정렬)
   ↓
3. 너무 가까운 친구는 밀어내기 (분리)
   ↓
4. 보이지 않는 바람 더하기 (흐름장)
   ↓
5. 실수 더하기 (가우시안 노이즈)
   ↓
6. 방향을 서서히 바꾸기 (관성)
   ↓
7. 그 방향으로 한 걸음 이동하기
   ↓
8. 화면에 그리기
   ↓
9. 1번으로 돌아가서 반복!
```

## 코드 구조 설명

### 2D 버전 (index.html)

```
index.html
├── CSS: 화면 스타일, 컨트롤 패널 디자인
├── HTML: 컨트롤 슬라이더, 프리셋 버튼
└── JavaScript:
    ├── Perlin Noise: 자연스러운 랜덤 패턴 생성기
    │   └── 일반 랜덤은 "지직거리는 TV"처럼 거칠지만
    │       Perlin 노이즈는 "구름"처럼 부드럽습니다
    │
    ├── gaussRandom(): 가우시안(종모양) 랜덤 숫자 생성
    │   └── 0 근처가 가장 많이 나오고, 큰 숫자는 드물게
    │       (동전 100번 던지면 50번 근처가 가장 많은 것처럼)
    │
    ├── Grid (공간 격자): 이웃 찾기 최적화
    │   └── 화면을 바둑판처럼 나누어서
    │       같은 칸에 있는 물고기만 비교 → 훨씬 빠름!
    │
    ├── Particle (입자): 물고기 한 마리의 데이터
    │   └── 위치(x,y), 방향(theta), 이동 궤적(trail)
    │
    ├── vicsekStep(): 매 프레임 물리 계산
    │   ├── 이웃 찾기
    │   ├── 평균 방향 계산 (Vicsek 정렬)
    │   ├── 분리력 계산
    │   ├── Perlin 흐름장
    │   ├── 가우시안 노이즈
    │   ├── 관성 적용
    │   └── 위치 업데이트
    │
    └── draw(): 매 프레임 화면 그리기
        ├── 배경을 살짝 어둡게 (잔상 효과)
        ├── 이동 궤적(트레일) 그리기
        ├── 방향 화살표 삼각형 그리기
        └── 글로우(빛나는) 효과
```

### 3D 버전 (3d.html)

```
3d.html
├── Three.js: 3D 그래픽 라이브러리
├── OrbitControls: 마우스로 카메라 회전
└── JavaScript:
    ├── Perlin Noise: 2D와 동일
    │
    ├── Particle3D: 3D 물고기
    │   ├── 위치: x, y, z (3차원!)
    │   ├── 방향: theta(좌우), alpha(상하) 두 개의 각도
    │   └── 속도: 구면좌표 → 직교좌표 변환
    │       vx = v × cos(theta) × sin(alpha)
    │       vy = v × sin(theta) × sin(alpha)
    │       vz = v × cos(alpha)
    │
    ├── Grid3D: 3D 공간 격자 (정육면체 칸)
    │
    ├── Curl Noise Flow: 3D 흐름장
    │   └── Perlin 노이즈의 "회전(curl)"을 계산
    │       → 물이 소용돌이치듯 흐르는 패턴
    │       → 물고기 무리를 자연스럽게 휘게 함
    │
    ├── InstancedMesh: 수천 개를 한번에 그리기
    │   └── 물고기를 하나하나 그리면 느림!
    │       "이 모양을 여기, 저기, 거기에 그려!"
    │       라고 한번에 말하면 → GPU가 빠르게 처리
    │
    └── 렌더링:
        ├── 원뿔(Cone): 물고기 모양
        ├── 트레일 선: 이동 궤적
        └── 글로우 점: 빛나는 효과
```

## 프리셋별 특징

| 프리셋 | 비유 | 특징 |
|--------|------|------|
| **fish** | 물고기떼 | 느리고, 밀집, 작은 그룹들이 합쳐졌다 갈라짐 |
| **birds** | 새떼 | 빠르고, 넓은 시야, 벽에서 크게 회전 |
| **swarm** | 벌레떼 | 아주 많고, 느리고, 긴 궤적, 구름 같은 움직임 |
| **chaos** | 혼돈 | 노이즈 높음, 빠르게 흩어졌다 모임, 불꽃놀이 같음 |

## 용어 사전

| 영어 | 한국어 | 쉬운 설명 |
|------|--------|-----------|
| Particle | 입자 | 물고기 한 마리 |
| Alignment | 정렬 | 주변 친구와 같은 방향으로 가기 |
| Separation | 분리 | 너무 가까우면 밀어내기 |
| Noise (η) | 노이즈 | 약간 삐뚤빼뚤 가는 정도 |
| Interaction Radius (R) | 상호작용 반경 | 친구를 알아볼 수 있는 거리 |
| Inertia | 관성 | 갑자기 못 꺾는 정도 |
| Flow Field | 흐름장 | 보이지 않는 바람 |
| Perlin Noise | 펄린 노이즈 | 구름처럼 부드러운 랜덤 패턴 |
| Gaussian | 가우시안 | 종 모양으로 가운데가 많은 랜덤 |
| Spatial Grid | 공간 격자 | 이웃 찾기를 빠르게 하는 바둑판 |
| Trail | 궤적 | 물고기가 지나간 자국 |
| Curl | 회전 | 소용돌이치는 흐름 |
| Boundary | 경계 | 화면의 끝 |
| Wrap | 순간이동 | 끝에서 반대편으로 나타남 |
| Steer | 조향 | 벽을 피해서 방향 틀기 |
